# Manfred Memorial Executive Brief

## What it is

A sourced memorial conversation interface.

## What it is not

It is not a claim that Manfred is literally present. It is not an unrestricted impersonation system. It is not an archive browser in the public flagship mode.

## Public surface

The flagship public surface is intentionally minimal:

- `Sprich mit der Erinnerung`
- short interaction hint
- install support
- live conversation loop

No public archive browsing, original recordings, voice A/B panel, source profile panel, provider names, or admin tooling should appear during the demo.

## Safety posture

- public JSON is sanitized
- raw bundle files are blocked
- public TTS rejects voice ID overrides
- voice consent is explicit
- difficult-memory questions are guarded first
- showtime/preflight scripts verify live behavior before presentation

## Presenter line

> This is a sourced memorial conversation interface. It does not claim that Manfred is literally present.
