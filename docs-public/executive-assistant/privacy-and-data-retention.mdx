# Privacy And Data Retention

Executive Assistant handles sensitive work context. Public docs should explain the boundary without publishing internal records or operational details.

## Data categories

- Account identity and provider connection status.
- Brief, signal, action, and approval metadata.
- Evidence links back to the connected source.
- Delivery channel binding status.
- Retention and export preferences.

## Retention posture

Keep only what is needed to explain the brief, preserve approvals, and recover user intent. Deletion and export behavior should be visible to the user before launch.

## Publication boundary

Documentation.AI should receive only public docs and sanitized public API descriptions. It should not receive provider logs, support records, private messages, exact calendar contents, decision history, or internal architecture details.
