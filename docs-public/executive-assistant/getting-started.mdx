# Getting Started

Start with one identity, one calendar, one inbox, and one delivery channel. Add more channels only after the first daily brief is correct.

## Setup path

1. Register with the approved email address.
2. Connect Google for Gmail and Calendar access.
3. Choose Telegram or WhatsApp as the first delivery channel.
4. Review the first brief and confirm which actions require approval.
5. Add the second delivery channel only after the first one is reliable.

## First useful outcome

The first useful outcome is not automation. It is a brief that clearly separates information, decisions, commitments, and suggested actions.

## Human review rule

Executive Assistant may prepare drafts and recommended actions, but sensitive sends, external commitments, and permission changes stay behind explicit approval.
